# Safe with Carmen

This app was built using Vite react template and npm package manager

In order to run the application follow the follwing steps

1. Open a terminal to this folder
2. Run the following command to install the required packages

```sh
npm install
```

3. After the installation is complete run the following app to run the app

```sh
npm run dev
```

4. If everything is correct. The app will be available on

```sh
localhost:5173
```
